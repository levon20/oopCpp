## Задание 3, часть 2

Описать два класса:

1. «Точка в декартовых координатах», хранящий три вещественных числа – координаты X,
Y и Z.

2. Точка в сферических координатах, хранящий три вещественных числа – два угла и
расстояние от точки до начала координат. В классах определить конструкторы, инициализирующие объекты переданными
значениями элементов-данных и значениями по умолчанию.

В обоих классах определить конструкторы преобразования типа и операторы
преобразования типа так, чтобы точка в декартовых координатах могла преобразовываться
в точку в сферических координатах, и наоборот.

В обоих классах перегрузить оператор << для объекта std::cout, так, чтобы данные
выводились на консоль.

В классе декартовых координат определить статический метод euclideanDistance( p1, p2) c
двумя параметрами, возвращающий расстояние между точками p1 и p2, которые задаются в
декартовых координатах.

В классе сферических координат определить статический метод bigCircleDistance( p1, p2) с
двумя параметрами, возвращающий расстояние между точками по поверхности Земли. При
этом считается, что угловые координаты точек – это географические долгота и широта,
координата-расстояние игнорируется, а радиус Земли принимается равным 6 371 000 м.

Благодаря наличию операторов преобразования типа эти функции могут работать с точками
обеих типов.

Создать тестирующий пример, демонстрирующий работу определённых методов.
Продемонстрировать работу с классом на следующем примере. Имеется файл с
географическими координатами точек на поверхности Земли (прилагается к заданию).
Определить максимальное расстояние между точками – евклидово и по поверхности Земли
(по дуге Большого круга). Вывести максимальное расстояние и соответствующие ему точки.
